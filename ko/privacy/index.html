개인정보처리방침

브로콜리스튜디오(이하 "운영자")는 카메라브릿지(camerabridge.io)를 운영하며 「개인정보 보호법」에 따라 이용자의 개인정보를 보호합니다. 카메라브릿지는 회원 가입 없이 쓸 수 있고, 아래의 최소한의 정보만 처리합니다.

처리하는 정보와 목적

의견 보내기의견 내용, 이메일(선택 입력), 접속지 식별값(IP 주소를 날짜별로 바꾼 해시값, IP 자체는 저장 안 함) — 의견 확인·답장, 스팸 막기(하루 5건 제한)
커뮤니티 게시판 (구글 로그인)구글 계정 고유번호를 알아볼 수 없게 바꾼 회원 번호(해시값), 닉네임, 글·댓글 내용(누구나 볼 수 있게 공개), 신고한 접속지 식별값(IP 주소를 날짜별로 바꾼 해시값, IP 자체는 저장 안 함)과 신고 내용 — 회원 확인·로그인 유지, 게시판 운영, 스팸·도배 막기(하루 글 5건·댓글 30건 제한), 신고 처리. 구글 이메일·이름·사진은 받지만 저장하지 않음
매장(딜러) 계정아이디, 매장 이름, 비밀번호(복원할 수 없는 해시값으로 저장) — 매장 전용 시세 화면 로그인
방문 기록접속 나라 코드, 화면 언어·통화, 들어온 사이트 주소(도메인만)·첫 주소, 모바일 여부, 머문 시간, 검색어·고른 모델·결과 수, 매장 링크 클릭, 탭마다 새로 만드는 무작위 번호 — 서비스 개선과 이용 통계. IP 주소·이메일·쿠키는 남기지 않음

보유 기간

  • 의견: 받은 날부터 1년 (답장이 이어지면 마지막 연락부터 1년)
  • 매장 계정: 계정을 없앨 때까지
  • 게시판 글·댓글: 글쓴이가 지울 때까지. 지운 글과 운영자가 내린 글은 분쟁·신고 확인을 위해 30일 비공개로 보관한 뒤 지움. 회원 번호·닉네임: 탈퇴를 요청할 때까지
  • 방문 기록: 기록한 날부터 1년
  • 기간이 지나거나 목적을 이루면 바로 지웁니다. 전자 파일은 복구할 수 없게 지웁니다.

쿠키와 브라우저 저장소

매장 계정으로 로그인할 때 로그인 유지용 쿠키(cb_dealer)를, 게시판에 구글로 로그인할 때 로그인 유지용 쿠키(cb_member, 90일)를 씁니다. 일반 이용자에게는 쿠키를 쓰지 않으며, 고른 언어·통화·배송 나라를 기억하려고 브라우저 저장소(localStorage)를 씁니다. 브라우저 설정에서 지울 수 있습니다.
