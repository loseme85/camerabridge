# 브라우저 재방문 통계

2026-11-11 구현. `/owner/usage`의 최근 방문에서 방문 시각 바로 아래에 `첫 방문` 또는 `이전에 N번 방문`을 표시한다.

## 집계 기준

- 첫 화면과 모델 페이지에서 `crypto.getRandomValues`로 128비트 무작위 식별값을 만들고 `localStorage.cb_browser`에 저장한다. 생성 후 365일이 지나면 새 값으로 바꾼다.
- 로그인 계정·이메일·IP에서 식별값을 만들지 않는다. IP 원문을 저장하지 않는다.
- 기존 탭 번호 `sessionStorage.cb_visit.sid`는 수집용으로 유지한다. 집계는 같은 브라우저의 기록 간격을 기준으로 한다. 기록 간격이 30분 미만이면 새 탭·외부 재유입·페이지 이동·반복 전송도 한 방문이며, 30분 이상 비면 같은 탭이어도 새 방문이다. 실제 사람 수를 뜻하지 않는다.
- 브라우저 식별값이 있는 기존·새 기록 모두 같은 30분 기준으로 다시 집계한다. 원본 기록은 수정하거나 삭제하지 않는다. 예전 기록은 기존 IP 일별 해시 집계를 유지하고 `이전 방문 확인 불가`로 표시한다. 과거 기록을 새 식별값에 소급 연결하지 않는다.
- 관리자 화면의 1일·7일·30일·특정 날짜 필터와 별개로 해당 브라우저의 보유 기록 전체(한국 날짜 기준 최근 365일)를 집계한다. 각 방문이 속한 구간보다 앞선 방문 구간 수만 표시한다. 해당 방문 자체와 그 뒤의 방문은 제외한다. 예를 들어 나중에 총 4번 방문했어도 첫 번째 행은 계속 `첫 방문`, 두 번째 행은 `이전에 1번 방문`이다.
- 브라우저 저장소 삭제·식별값 만료·다른 브라우저·다른 기기는 별도 방문자다. 저장소 접근이 막히면 기존 방문 기록은 남기되 브라우저별 재방문은 식별하지 않는다.
- 첫 화면과 모델 페이지의 식별값 생성 부분은 같은 규칙을 유지한다. 회귀 검사는 두 실제 수집 코드를 각각 실행한다. `beta.html`과 `app/templates/beta.html`도 함께 갱신한다.

## 저장과 장애 처리

`api/usage.py`가 `vid`를 정확히 32자리 소문자 16진수로 검증한다. 기존 `usage_events.entry` JSON에 저장하므로 데이터 이동은 필요 없다. `pgstore.ensure_schema()`가 `vid` 조회용 인덱스를 만든다.

`pgstore.browser_history()`는 전체 보유 기록에 `LAG`·누적합을 적용해 브라우저별 30분 방문 구간을 만든다. 화면의 방문 행·요약·누적 횟수는 같은 구간을 쓴다. 중간 기록이 화면의 5,000건 상한 때문에 빠져도 전체 이력의 구간을 유지한다. 별도 누적 표를 두지 않아 원본 기록을 지우면 집계에서도 빠진다. 집계 쿼리에는 화면 조회의 5,000건 상한을 적용하지 않는다. Neon 연결이 없거나 누적 조회가 실패하면 `이전 방문 확인 불가`로 표시하며 첫 방문이라고 추정하지 않는다.

`/?notrack=1`은 해당 브라우저의 기록을 끄고 브라우저 식별값을 지운다. 이미 열린 다른 탭도 다음 전송 때 끄기 상태를 확인한다. `/?notrack=0`으로 다시 켤 수 있다. 관리자 제외 쿠키와 봇 제외 동작을 유지한다. 개인정보 안내의 한국어·영어·일본어에 저장 방식·기간·끄기 링크를 반영했다.

## 화면과 중복 표시 수정 (2026-11-11)

첫 구현은 같은 브라우저의 전체 첫·최근 방문을 매 방문 행에 반복해서 보여 줘, 동일 시간이 여러 방문처럼 보였다. 탭 번호도 방문으로 세어 여러 탭에서 수치가 부풀 수 있었다.

한 차례 전체 이력을 별도 표로 나눴으나, 사장님이 원하는 것은 그 방문자가 그전에 몇 번 왔는지 바로 확인하는 것이었다. 최종 화면은 기존 최근 방문 표의 방문 시각 아래에 `첫 방문` 또는 `이전에 N번 방문`만 표시한다. 브라우저 번호·이력 링크·별도 이력 표·반복되는 첫/최근 방문 시각·긴 설명을 제거했다. 휴대폰에서도 옆으로 밀지 않고 이전 방문 횟수를 볼 수 있다. 방문 시각은 서버의 최초 기록 시각을 한국 시간(KST)으로 통일해 표시한다. 표에 표시된 방문 시각이 최신인 순서로 정렬하며, 마지막 활동 시각으로 순서를 바꾸지 않는다. 해외 현지 시각·중복 한국 시각 설명은 표시하지 않는다.
